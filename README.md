### About

Independent security researcher focused on practical offensive operations:
authenticated and unauthenticated attack paths in Active Directory environments,
802.11 wireless assessments, and applied cryptographic protocol review.

I keep things lab-first: every technique is validated in isolated environments
against authorized targets only.

### Current focus

- Active Directory attack-path mapping (BloodHound, custom Cypher queries)
- 802.11 monitor-mode auditing (mt76 chipset, aircrack-ng suite)
- Cryptographic implementation review of messaging protocols
- Bug bounty program research within scope
